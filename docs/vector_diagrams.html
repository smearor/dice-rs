Dice Reference Vector Diagrams

Each colored arrow represents the gravity vector when that face is resting on the table. The vector points from the die center toward the downward face.

When the accelerometer reads (x, y, z), the interpret() function finds the closest reference vector (nearest neighbor by squared Euclidean distance) and returns the corresponding face number.

Three views are shown for each die type to disambiguate vectors that overlap in a single projection: Isometric (3D perspective), Front (X-Z plane), and Top (X-Y plane).
