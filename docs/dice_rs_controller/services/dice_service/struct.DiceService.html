pub struct DiceService {
    dice: Dice,
    device_name: String,
}
Expand description

Service for pro-dice business operations.

Encapsulates dice hardware commands and config persistence, keeping UI widgets free of business logic. All fire-and-forget methods spawn async tasks internally so callers never block.
