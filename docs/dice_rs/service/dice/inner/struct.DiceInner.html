Expand description

Internal shared state for a connected dice. Stored behind Arc so all Dice clones share the same state.

Fields§

§name: String

Advertised device name (e.g. “GoDice_7D8E7D_O_v04”).

§peripheral: BtleplugPeripheralWrapper

BLE peripheral for write/subscribe operations.

§write_char: Characteristic

Write characteristic (NUS RX).

§notify_char: Characteristic

Notify characteristic (NUS TX).

§event_sender: Sender<DiceEvent>

Broadcast sender for DiceEvent stream.

§dice_type: Arc<AtomicU8>

Current dice type stored as AtomicU8 for lock-free reads. Converted to DiceType via TryFrom<u8> at use site. This avoids async lock overhead in the notification task hot path. Arc-wrapped so it can be cloned into the notification task.

§pending_battery: Arc<Mutex<VecDeque<Sender<u8>>>>

FIFO queue of pending battery level request senders.

§pending_color: Arc<Mutex<VecDeque<Sender<DiceColor>>>>

FIFO queue of pending dice color request senders.

§pending_calibration: Arc<Mutex<VecDeque<Sender<bool>>>>

FIFO queue of pending calibration request senders.

§notification_handle: Mutex<Option<JoinHandle<()>>>

JoinHandle of the notification parsing task. Aborted on disconnect/reconnect to prevent orphaned tasks.

§monitor_handle: Mutex<Option<JoinHandle<()>>>

JoinHandle of the connection monitor task. Aborted on disconnect/reconnect to prevent orphaned tasks.

§led_throttle: Mutex<LedThrottleState>

LED write throttle state for coalescing rapid set_leds calls.

§led_debounce_handle: Mutex<Option<JoinHandle<()>>>

JoinHandle of the LED debounce task.

§led_notify: Arc<Notify>

Notify the LED debounce task that a new color is pending.

§calibration_offset: Arc<RwLock<Option<AccelerationOffset>>>

Software calibration offset applied to accelerometer readings before face value interpretation. None when no software calibration has been performed.

Uses std::sync::RwLock (not tokio::sync::RwLock) because the lock is only held for a trivial copy — never across .await. This avoids unnecessary task-scheduling overhead on every sensor event in the notification task. Arc-wrapped so it can be cloned into the notification task.

§charging_state: Arc<AtomicU8>

Last known charging state, updated by the notification task. Stored as AtomicU8 using ChargingState repr. Arc-wrapped so it can be cloned into the notification task.
