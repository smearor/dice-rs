Expand description

Handle to a connected GoDice device.

Clone is cheap (just an Arc clone). All clones share the same underlying connection state.

pub async fn set_leds(&self, led1: LedColor, led2: LedColor) -> Result<()>

Set both RGB LEDs to the given colors.

Rapid successive calls are coalesced: if set_leds is called again within LED_DEBOUNCE_MS, only the most recent colors are written. This prevents BlueZ/DBus socket buffer overflow when an application fires many color changes in quick succession.

Source

pub async fn set_leds_immediate( &self, led1: LedColor, led2: LedColor, ) -> Result<()>

Set both LEDs without debounce — writes immediately.

Use this for one-shot LED commands where coalescing is undesirable (e.g. CLI commands, calibration sequences).
